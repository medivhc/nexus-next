# Nexus 浏览器测试选择契约

浏览器任务执行两次产品构建。`tools/build-web.sh` 为 `wasm32-unknown-unknown` 构建 `nexus-web`，工作流为 Linux 构建 `nexus-cli` 供浏览器端到端测试调用。两者都是浏览器任务的构建根。

- 构建根和经普通依赖或构建依赖可达的仓库内 Cargo 包都是构建输入。工作区继承和重命名由 Cargo 解析。为保守覆盖，目标专属和可选依赖声明也参与可达性计算。单独通过开发依赖可达的包不产生此项义务。
- PR 中任一构建输入包的源码或 Cargo 清单变更，必须令 `web=true`。加入其他路径或改变输入顺序都不能撤销这项选择。
- 主分支 push、定时和手动运行必须选择浏览器任务。纯说明文档，以及仅涉及 Android、系统仿真或测试工具包且这些包不在构建闭包中的 PR，保留跳过行为。工作流可以基于独立的风险规则额外选择浏览器任务。
- 模型以 Cargo 提供的依赖声明和 Git 跟踪的代表文件为输入。它枚举空集、单文件和二文件变更集，以每个包的一份源码和一份 Cargo 清单覆盖包级路径，并独立回放非 PR 事件。
