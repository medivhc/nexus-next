# M2.3 功能点：网页终端

页面里的终端由「网页节点核心」驱动：连会话、转发输入和输出、确认、心跳、断线重连都在核心里，
页面只负责显示（xterm.js）和收集按键、尺寸变化。测试里用同一份核心加一个内存终端扮演页面。

## FP-2.3-01 恢复屏幕、多客户端、尺寸跟随（R30）
- Given home 上的会话 main 正被 laptop 上的 `nexus ssh home` 连着，屏幕上有一行 before-web
- When 浏览器登录后连上 home/main
- Then 页面的屏幕上有 before-web（恢复屏幕）
- When 在页面里输入命令
- Then 页面和 laptop 的终端上都看到输出（多客户端共享）
- When 页面的尺寸变成 100x30，然后在页面里输入 `stty size`
- Then 输出 `30 100`（尺寸跟随最近输入的客户端）

## FP-2.3-02 断线自动重连（R34）
- Given 浏览器连着 home/main
- When 浏览器和 home 之间断网 25 秒（长到两端都认定连接已死），期间会话里的命令继续输出
- Then 页面显示「连接中断，正在重连」；网络恢复后自动连回同一个会话，看到断网期间的输出，输入照常
- And 不需要再用通行密钥

## FP-2.3-03 不能再连时停止重连（R34、R31）
- Given 浏览器连着 home/main
- When 断网期间管理设备撤销了这个通行密钥
- Then 网络恢复后重连被拒绝，页面的终端结束并显示原因，不再重试

## FP-2.3-04 本机托管页面（R30）
- When `nexus web serve --dir <页面目录>`
- Then 在 `http://localhost:<端口>/` 提供页面，WebAssembly 文件的类型是 `application/wasm`；
  只监听本机地址；输出页面地址
- And `nexus web enroll --page http://localhost:<端口>` 得到的登记链接指向这个页面（开发时用本机页面登记和登录）
- When 请求目录之外的路径（例如带 `..`）
- Then 404
