# M1.6 功能点：对本机程序表现为 SSH

本机的 ssh 通过一条 ProxyCommand 规则连到 Nexus，不开任何端口，不配置任何密钥：

```
nexus ssh-config >> ~/.ssh/config
```

之后 `ssh <设备名>.nexus` 就能用。认证完全由 Nexus 的设备身份（或 `NEXUS_AGENT` 给出的 agent 凭据）承担；
SSH 这一层只在本机的两个进程之间运行。

## FP-1.6-01 执行命令（R24）
- When `ssh home.nexus 'echo $((40+2)); echo oops >&2; exit 3'`
- Then 标准输出 `42`，标准错误有 `oops`，退出码 3
- And 标准输入原样送到远端命令
- And 第二次连接不需要任何确认；全程可以用 BatchMode（不允许交互）
- When 目标设备不存在
- Then ssh 失败，错误里说明是哪个名字

## FP-1.6-02 scp（R24）
- When 用 scp 把一个文件传到 home 再传回来
- Then 两次传输都成功，内容一致（scp 默认走 SFTP；远端需要有系统自带的 sftp-server）

## FP-1.6-03 git（R24）
- When 在 home 上建一个裸仓库，从 laptop 推送、再克隆
- Then 克隆出来的内容和推送的一致

## FP-1.6-04 交互式登录进入常驻会话（R24、R05）
- When `ssh -tt home.nexus`，输入一条需要时间的命令后断开
- Then 命令照常完成，之后 `nexus ssh home` 能看到它的输出（两者是同一个 main 会话）
- When 在会话里 `exit 4`
- Then ssh 以退出码 4 结束

## FP-1.6-05 上手成本有记录（R27）
- 从两台设备都装好并运行常驻程序开始，到第一次进入另一台设备的终端：
  init、join、approve、ssh 四条命令；步骤和耗时写入测试输出目录的 onboarding.json
