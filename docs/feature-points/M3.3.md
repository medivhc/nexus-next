# M3.3 功能点：出口

路由规则多两种出口：

- **经网络里的一台设备出去**：`nexus route add --domain example.com --via home`。连接经 Nexus 到 home，由 home 连到目标。
  home 要先 `nexus exit on` 开放出口；开放后名册里自己的设备默认可用，判定和审计在 home 上（能力 `net.exit`，资源 `<设备>/exit`）。
  出口不替别人连出口设备自己的本机地址（127.0.0.0/8、::1、0.0.0.0）：本机上的程序要给别人用，应当发布成服务。
- **交给上游 SOCKS5**：`nexus route add --domain example.com --socks5 127.0.0.1:7890`，例如本机已有的代理工具。

出口设备不再按自己的规则转发（不做多跳）。

## FP-3.3-01 经设备出去（R42）
- Given home 上有一个外面可以访问的服务（测试里是 home 所在机器的一个非本机地址）；laptop 有规则 `--cidr <地址>/32 --via home`
- When home 还没有开放出口，laptop 经入口访问这个地址
- Then 被拒绝（SOCKS5「规则不允许」，HTTP 403）
- When home `nexus exit on` 之后再访问
- Then 拿到服务的回应（SOCKS5 和 HTTP 代理都可以）；home 的审计里有一条 `net.exit` 允许的记录
- And `nexus route explain` 说明命中第几条规则、经哪台设备出去；`nexus route ls` 列出出口设备
- When home `nexus exit off` 之后再访问
- Then 又被拒绝

## FP-3.3-02 出口不连出口设备的本机地址（R42）
- Given home 开放了出口，home 本机 127.0.0.1 上有一个服务；laptop 有规则 `--cidr 127.0.0.0/8 --via home`
- When laptop 经入口访问 127.0.0.1:<端口>
- Then 被拒绝

## FP-3.3-03 出口设备要在名册里（R42）
- `--via` 一台不存在的设备：103（和其他命令一样）；`--via` 本机：107（本机出去就是直连）

## FP-3.3-04 上游 SOCKS5（R42）
- Given laptop 本机有一个 SOCKS5 代理；规则 `--domain far.test --socks5 127.0.0.1:<端口>`
- When 经入口访问 www.far.test:80
- Then 连接交给上游代理，目标原样是 www.far.test:80（不在本机解析）
- When 上游代理拒绝了这个目标
- Then 入口回应「连接被拒绝」（HTTP 502）
- When 上游代理没有在运行
- Then 入口回应「主机不可达」（HTTP 502）
- And `--socks5` 后面不是 主机:端口 时：107
