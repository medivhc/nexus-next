# M2.5 功能点：网页节点的边界与度量

## FP-2.5-01 经锚点马上可达（R28、R36）
- Given 一台刚启动、以自建中继（锚点）为中继的设备
- When 只经中继的节点（浏览器）连它
- Then 1.5 秒内连上（之前要等中继的 QUIC 地址探测超时，约 3 秒）
- 原因：锚点只提供中继，不提供 QUIC 地址探测；登记自建中继时不再声明这一项

## FP-2.5-06 锚点上中继的探测不占用页面的连接（R35）
- When 浏览器里的 iroh 请求中继的探测路径（`/ping` 等），之后在同一条保持的连接上请求页面
- Then 探测回应后连接关闭，页面的请求走新的连接，拿到的是页面而不是中继的首页
- （浏览器端到端测试关闭后重新打开页面时发现：页面变成了中继的首页）

## FP-2.5-02 关闭即离开（R32）
- Given 浏览器登录后连着 home 的会话
- When 关闭页面
- Then 同一个浏览器里（同一来源）没有任何存储：本地存储、会话存储、Cookie、IndexedDB、缓存存储、
  Service Worker 都为空
- And home 上这个会话的客户端数回到 0（页面来得及时主动离开；来不及时设备 15 秒没有心跳就判定断开），
  会话本身继续运行
- And 重新打开页面后必须再用通行密钥登录（没有任何东西能恢复之前的登录）

## FP-2.5-03 页面被冻结或切到后台后自动恢复（R34）
- Given 浏览器连着 home 的会话
- When 页面被浏览器冻结 20 秒（切到后台、锁屏时浏览器会这样做；超过设备判定断线的 15 秒）
- Then 恢复后终端自动重连到同一个会话，输入照常，不需要再用通行密钥

## FP-2.5-04 页面体积有预算（R36）
- 页面的 WebAssembly gzip 后不超过 1.2 MB（按体积优化编译后约 1.03 MB）；超出时浏览器端到端测试失败

## FP-2.5-05 网页上手成本有记录（R36）
- 在陌生电脑上从打开页面到进入会话：打开页面 → 点「用通行密钥登录」并选通行密钥 → 点设备的「终端」，共 3 步
- 浏览器端到端测试记录每一步的耗时，从点登录到出现提示符不超过 2 秒（本机网络）
