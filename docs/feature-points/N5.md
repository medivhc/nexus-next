# N5 功能点与验收标准：自有 VPS 候选路径对比与自适应选路

## FP-N5-01 无明显优势时保持直连（U05）
- **Given** `direct`（p95=40ms, jitter=4ms, loss=0）与 `vps-relay`（p95=38ms, jitter=4ms, loss=0），`min_improvement_pct = 15`
- **When** 对 `InteractiveGame` 执行 `choose_path`
- **Then** 返回 `Keep { path_id: "direct" }`，不因微小波动切换中继

## FP-N5-02 实测显著改善时才启用自有 VPS 加速（U05）
- **Given** `direct`（p95=140ms, jitter=30ms, loss=400bps）与 `vps-relay`（p95=45ms, jitter=5ms, loss=0），驻留时间 ≥ `min_dwell_secs`
- **When** 对 `InteractiveGame` 执行 `choose_path`
- **Then** 返回 `Switch { from: "direct", to: "vps-relay", .. }` 并报告改善百分比

## FP-N5-03 滞回与最短驻留防震荡
- **Given** 当前路径驻留时间 `< min_dwell_secs`
- **When** 候选路径改善超过阈值但当前路径仍健康
- **Then** 返回 `Keep`，等待驻留窗口满足后再切换

## FP-N5-04 账号稳定业务允许同出口前段优化、禁止跨出口漂移（U04）
- **Given** `AccountStable` 当前路径 `direct->jp-vps`（`actual_exit = "jp-vps"`），候选含 `relay-a->jp-vps`（`actual_exit = "jp-vps"`, 延迟大降）与 `direct->us-vps`（`actual_exit = "us-vps"`, 延迟极低）
- **When** 执行 `choose_path`
- **Then** 允许切换至 `relay-a->jp-vps`（同出口前段优化），绝不切换至 `direct->us-vps`

## FP-N5-05 过期/不足样本降权与批量传输规避计费链路
- **Given** 中继候选样本过期（`age_secs > max_sample_age_secs`）或样本量 `< min_samples`
- **Then** 不采信该候选；`Bulk` 场景自动跳过 `metered == true` 的计费候选
