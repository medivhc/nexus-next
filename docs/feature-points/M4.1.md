# M4.1 功能点：本地内容运行时

工作区是一棵版本化的内容树：文件按内容切成块（FastCDC 16/64/256 KiB），块、文件清单、目录树和提交都按内容寻址（BLAKE3）。
工作区有一份「工作树」（尚未提交的状态，同样按内容寻址、只在本机）和一个「头」（最近的提交）。
写入改工作树；`commit` 把工作树变成一次不可变的提交。这一步还都在本机，同步在 M4.2。

路径写作 `<工作区>:/<路径>`，例如 `work:/src/main.rs`；`work:` 或 `work:/` 是根目录。
工作区名：小写字母、数字、连字符，1 到 32 个字符。

## FP-4.1-01 创建、导入、列出（R47）
- `nexus drive create work` 创建空的工作区；同名再建：107；名字不合法：107
- `nexus drive import <本地目录> work:/` 把目录里的文件、子目录、符号链接导入工作树（可执行位保留）；
  导入到 `work:/sub` 时放在 sub 下；工作区不存在：109；本地目录不存在：107
- `nexus drive ls`：列出工作区（名字、头、未提交的改动数）
- `nexus drive ls work:/src`：列出目录（名字、类型 file/dir/symlink、大小）；路径不存在：109；对文件 ls 列出它自己
- `nexus drive cat work:/src/main.rs` 输出内容；是目录：107；不存在：109

## FP-4.1-02 按范围读（R48，本地部分）
- `nexus drive cat work:/big.bin --offset N --length M` 只输出这一段；越过文件末尾时输出到末尾为止
- 跨多个块的范围、恰好落在块边界上的范围，结果和原文件相同

## FP-4.1-03 写入、提交、历史（R49）
- `nexus drive put work:/a.txt`（内容来自标准输入）新建或覆盖文件；中间的目录自动建立；`--exec` 设可执行位
- `nexus drive rm work:/a.txt`（`-r` 删目录）；不存在：109
- `nexus drive status work`：列出未提交的改动（added / modified / deleted 和路径）；没有改动时为空
- `nexus drive commit work -m 说明`：生成提交，返回提交号；没有改动时：107（没有可提交的）
- `nexus drive log work`：提交历史，新的在前（提交号、说明、设备、时间）
- `nexus drive cat work:/a.txt --at <提交号>` 读旧版本；提交号可以是前缀（至少 8 个十六进制字符）；不存在：109
- 内容相同的文件只存一份（导入两个相同的大文件，存储增长约一份）——单元测试验证
