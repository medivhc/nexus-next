# M3.1 功能点：发布服务与按路径连接

一台设备上只监听本机的服务（例如 home 上 127.0.0.1:8080 的网页服务）可以发布给网络里的其他主体使用。
发布方只声明三样东西：它在哪（本机地址，只有发布方知道）、谁能用（授权）、怎么用（协议和使用方需要的环境变量）。

使用方用路径 `home/web` 访问它：`nexus connect home/web` 把标准输入输出接到服务上，
`--listen` 在本机开一个端口转发过去。使用方不持有任何密钥，目标设备按名册判定每一次连接，并留下审计记录。

授权：能力 `svc.connect`，资源 `<设备>/svc/<服务>`。名册里的设备默认可以使用；agent 和网页登录需要明确的授权，
例如 `svc.connect@home/svc/web` 或 `svc.connect@**`。

## FP-3.1-01 发布、列出、撤销发布（R37、R39）
- When home 上 `nexus publish web --port 8080 --proto http --env BASE_URL=http://{addr}/v1`
- Then 输出发布结果；`nexus ls home --json`（在 laptop 上）列出 web：路径 `home/web`、名字 `web.home.internal`、
  协议 http、环境变量模板 `BASE_URL=http://{addr}/v1`；不包含本机端口
- When 名字已发布、名字不合法（只能用字母、数字、- 和 _），或环境变量写法不对
- Then 退出码 107
- When `nexus unpublish web`
- Then 列表里不再有它；撤销不存在的名字退出码 109

## FP-3.1-02 按路径连接（R38）
- Given home 发布了一个回声服务 echo
- When laptop 上 `nexus connect home/echo`，标准输入是 hello
- Then 标准输出是 hello（标准输入结束后对方收到结束，回应完整送回）
- When 服务名不存在
- Then 退出码 109
- When 发布方的本机服务没有在运行
- Then 退出码 108，说明连不上本机服务
- When `nexus connect home/web --listen 127.0.0.1:0`（真实后端）
- Then 输出本机地址；本机程序连这个地址，就是在用 home 上的 web

## FP-3.1-03 授权与审计（R37、R38）
- Given agent 只有 `node.info@**`
- When 它连 home/echo
- Then 退出码 105；`nexus ls home` 里看不到任何服务
- When 授权 `svc.connect@home/svc/echo`
- Then 能连上，且列表里只有 echo
- And home 的审计记录里有这次 svc.connect，主体是这个 agent
- And 网页登录的默认权限不包含服务
