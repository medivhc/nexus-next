# M1.1 功能点：身份、名册与授权判定

本里程碑只实现纯逻辑。这些功能点由 `nexus-core-proto` 的单元测试、属性测试和授权矩阵验证；
端到端的验证在 M1.2 和 M1.5 中完成，届时对应的需求才在 `FEATURES.md` 里标为已实现。

## FP-1.1-01 签名不能跨用途复用（R16）
- Given 根密钥对一份名册签了名
- When 把这个签名原样当作 agent 证书或 agent 请求的签名
- Then 校验失败

## FP-1.1-02 名册只认受信任的根（R01、R02、R18）
- Given 一台设备信任某个根公钥
- When 收到一份由另一把密钥签名的名册，或签名之后被改动过的名册
- Then 拒绝它，并保留原来的名册
- 边界：名册里出现重复的设备标识或重复的设备名，同样拒绝

## FP-1.1-03 名册只会前进（R02、R18）
- Given 本机已有某个版本的名册
- When 收到版本号不高于它的名册
- Then 拒绝；只有版本号更高的才被接受
- 性质：无论以什么顺序收到一组名册，最终都停在其中版本最高的那一份

## FP-1.1-04 名册内的设备拥有全部权限（R12）
- Given 请求来自名册内的设备，且以设备自己的身份发出
- When 请求任意能力和资源
- Then 允许
- 边界：名册外的设备（包括被移出名册即被吊销的设备）一律拒绝

## FP-1.1-05 agent 只能做被授权的事（R12）
- Given 一张有效的 agent 证书，授权「`term.exec` 作用于 `home`」
- When agent 请求 `term.exec` 作用于 `home`
- Then 允许
- When agent 请求 `term.session.attach` 作用于 `home`，或 `term.exec` 作用于 `office`
- Then 拒绝，原因是没有匹配的授权
- 通配：`term.*` 匹配所有以 `term.` 开头的能力；资源里 `*` 匹配一段，结尾的 `**` 匹配零段或多段

## FP-1.1-06 授权有有效期（R13）
- Given 一张有效期为 [生效时间, 失效时间) 的证书
- When 当前时间早于生效时间，或不早于失效时间
- Then 拒绝，分别说明是尚未生效还是已经过期
- 边界：恰好等于生效时间时允许；恰好等于失效时间时拒绝

## FP-1.1-07 撤销的 agent 立即失效（R14）
- Given 名册里列出了某个 agent 已被撤销
- When 这个 agent 用仍在有效期内的证书发起请求
- Then 拒绝

## FP-1.1-08 请求内容无法扩大权限（R16）
- Given 一张有效证书
- When 有人改动证书中的授权、改用另一把密钥签发证书、
  用别人的密钥签署请求、把发给 A 节点的请求拿到 B 节点使用、
  或签署的动作与实际请求的动作不一致
- Then 全部拒绝，并各自给出原因
- 边界：签署时间与当前时间相差超过 5 分钟的请求视为过期，拒绝

## FP-1.1-09 agent 只能经由名册内的设备发起请求（R12、R18）
- Given 一张有效证书
- When 承载请求的连接来自名册外的设备
- Then 拒绝

## FP-1.1-10 每次判定都有审计记录（R17）
- Given 任意一次判定
- When 判定完成
- Then 同时得到一条审计事件，包含时间、对端设备、主体、能力、资源和结果；被拒绝时包含原因

## FP-1.1-11 看不到未被授权的东西（R15）
- Given 一张只授权 `home/session/build` 的证书
- When 判断这个 agent 能否看到 `home`、`home/session/build`、`home/session/other`、`office`
- Then 依次为：能、能、不能、不能
