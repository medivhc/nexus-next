# M8.1 功能点：网页端浏览工作区（Drive）

## 模型

- **复用现有协议，不升主版本**：浏览器节点继续使用 `Proto::Rpc`（协议主版本 19，不新增或修改线协议消息）：
  - 通过 `Request::DriveInfo` 发现目标设备上当前通行密钥有权读取的工作区及其最新提交头（`head`）。
  - 通过 `Request::DriveGet` 按需拉取 `Commit`、`Tree`、`FileManifest` 和内容块（chunk），在浏览器端使用纯逻辑库 `nexus-drive-core` 解码，并逐对象校验 BLAKE3 哈希。
  - 若工作区刚创建还没有任何提交（`head` 为空），页面显示「工作区暂无已提交文件」，不报错。
- **最小权限与只读边界（R68）**：
  - `nexus web enroll` 的默认权限保持不变（`term.session.*@**` 与 `node.info@**`），默认**不授予** `drive.read`。
  - 需要网页端浏览文件时，在登记通行密钥时显式授权，例如 `--grant 'drive.read@**'`（所有设备的全部工作区）或 `--grant 'drive.read@*/drive/work'`（仅限指定工作区）；同时需要 `node.info` 用于发现设备与工作区列表。
  - 未授权的工作区在网页端不可见（沿用目标设备 `DriveInfo` 的按主体过滤）；网页端仅提供只读浏览、预览与下载，不暴露写入、删除或提交操作。
  - 每次 `DriveGet` 请求都在目标设备经过 `authz::decide` 判定并写入 `audit.log`（主体为通行密钥名字，能力为 `drive.read`，资源为 `<设备>/drive/<工作区>`）。
- **按需拉取、预览上限与安全边界**：
  - 仅拉取当前展开目录的 `Tree` 和当前查看/下载文件所需的块，不做全量同步；所有对象仅驻留页面内存，关闭页面后浏览器零留存（R32）。
  - **文本预览**：对合法 UTF-8 文本文件默认最多拉取前 **256 KiB**；超过上限时明确提示「已截断显示前 256 KiB」并提供下载完整文件入口。二进制文件不尝试乱码渲染，直接提示文件大小与下载按钮。
  - **图片预览**：支持浏览器原生格式（PNG、JPEG、WebP、GIF、SVG），单图预览上限 **16 MiB**（超过时提示直接下载）。所有图片（特别是 SVG）一律通过独立 `Blob` URL 挂载到 `<img>` 渲染，严禁直接注入页面 DOM，防止同源 XSS；切换文件或离开视图时及时 `URL.revokeObjectURL`。
  - **符号链接**：目录列表展示为符号链接并标明目标路径，不自动递归跟随，防止循环引用或语义混淆。
- **分层实现落点**：
  - `crates/nexus-web-core`：新增 `drive.rs`（引入纯逻辑 `nexus-drive-core`，保持不依赖具体传输与系统调用，满足 `tools/check.py` 架构约束），提供工作区发现、目录列出、按范围读取与哈希校验能力。
  - `crates/nexus-web`：向前端暴露 WASM 异步接口（列工作区、列目录、读文件片段/整文件）。
  - `web/`：在设备详情视图中增加「文件」标签页（与「终端」并列），提供工作区选择、面包屑导航、目录项列表（名称、类型、大小）、文本/图片预览面板与下载按钮。

## FP-8.1-01 最小权限与工作区发现（R68、R33、R51）
- Given 设备 `anchor` 开启 `drive serve on`，上有 `work` 和 `secret` 两个已提交工作区
- When 用默认权限（不含 `drive.read`）的通行密钥登录网页节点
- Then `anchor` 的文件页看不到任何工作区（或提示无文件读取权限），直接发起 `DriveGet` 返回 `Denied`
- When 另用带 `--grant 'drive.read@*/drive/work'`（及 `node.info@**`）的通行密钥登录
- Then 仅能看到 `work`，看不到 `secret`；直接请求 `secret` 的对象被目标设备拒绝并在 `anchor` 的 `audit.log` 中记录 `deny`

## FP-8.1-02 目录浏览与空工作区（R68）
- Given `work` 工作区包含嵌套目录 `src/lib.rs`、根目录 `README.md`、符号链接 `latest -> src/lib.rs`；另有一个未提交过的空工作区 `empty`
- When 网页端打开 `work:/` 并进入 `src/`
- Then 根目录正确列出 `README.md`（文件及字节数）、`src/`（目录）、`latest`（符号链接及目标）；进入 `src/` 列出 `lib.rs`；点击面包屑可返回上级
- When 网页端打开 `empty`
- Then 显示空状态提示而非错误

## FP-8.1-03 文本与图片预览（R68）
- Given `work` 中包含小文本 `README.md`、超过 256 KiB 的大日志 `big.log`、合法 PNG 图片 `logo.png`、SVG 图片 `icon.svg` 以及随机二进制文件 `data.bin`
- When 依次在网页端预览这些文件
- Then `README.md` 完整显示文本内容；`big.log` 仅拉取前 256 KiB 并提示已截断；`logo.png` 与 `icon.svg` 通过 `<img>` 正常渲染且不执行 SVG 内嵌脚本；`data.bin` 提示不支持预览并提供下载入口

## FP-8.1-04 按需下载与内容校验（R68）
- Given `work` 中包含跨多块（如 4 MiB）的文件 `archive.bin`
- When 网页端仅浏览 `work:/` 目录而不点击下载
- Then 仅拉取 `Commit` 与 `Tree` 对象，不拉取 `archive.bin` 的内容块
- When 点击下载 `archive.bin`
- Then 按清单分块拉取、逐块校验 BLAKE3 哈希后触发浏览器下载，下载内容与源文件逐字节一致；若对端返回损坏块则明确报错并中止下载

## FP-8.1-05 撤销通行密钥与关闭即离开（R31、R32、R68）
- Given 网页端正在浏览 `work`
- When 管理设备执行 `nexus web revoke <label>` 并将新名册推送到 `anchor`
- Then 网页端后续的目录展开、预览或下载请求立即被拒绝并提示原因
- When 关闭浏览器标签页
- Then 浏览器本地存储（localStorage / IndexedDB / CacheStorage）中不留存任何工作区内容或会话凭证

## 测试方式

- **L1 纯逻辑 / `nexus-web-core` 单元测试**：文本/图片类型判定、256 KiB 截断范围计算、对象哈希损坏检测。
- **L2 / L3 验收场景**（`crates/nexus-cli/tests/web_drive.rs`，仿真与真实双后端）：覆盖 FP-8.1-01 至 FP-8.1-05（使用 `nexus-testkit` 的 `Browser` 角色）。
- **浏览器 E2E**（`tools/web-e2e`）：Chromium + 虚拟认证器下验证登录、展开目录、文本/图片预览、下载与关闭后零存储。
- **需求追溯**：新增需求 `R68 网页浏览工作区` 到 `FEATURES.md`，由 `tools/check.py` 自动校验覆盖率。
