# M8.3 功能点：网页节点发布硬件能力（摄像头、麦克风、位置）

对应需求：`FEATURES.md` **R72**（并遵循 **R31**、**R32**）。

## 设计要点

1. **向前兼容的协议扩展（`WIRE_VERSION = 19, WIRE_MINOR = 1`）**：
   - 在 `Request` 末尾新增 `HardwareList`、`HardwareCapture { kind }`；在 `Response` 末尾新增 `HardwareList(Vec<HardwareKind>)`、`HardwareCapture(HardwareCapture)`，不改变任何既有枚举变体序号，保证与 M7.1 旧版本互通。
   - 硬件类别固定为三项：`camera`（摄像头快照）、`microphone`（麦克风录音片段）、`location`（地理坐标）。
2. **默认全关、逐项显式同意**：
   - 浏览器登录后默认**不开放任何硬件能力**（`enabled` 为空集合）。
   - 用户必须在页面上针对每一项能力单独点击开启并经过浏览器权限弹窗（`getUserMedia` / `navigator.geolocation`）；未开启的能力收到远端请求时直接返回 `ErrorCode::Denied`。
   - 关闭某项能力或离开/关闭页面（`pagehide`）时立即停止所有采集轨道并拒绝后续请求（严格遵守 R32「关闭即离开」）。
3. **只信任当前网络名册内的设备**：
   - 网页节点收到入站 `Proto::Rpc` 硬件请求时，校验对端 `NodeId` 必须属于当前会话可见的受信任设备列表；未在名册中的陌生节点直接拒绝（`ErrorCode::Denied`）。
4. **页面实时显示「谁在用」**：
   - 每次远端设备调用硬件能力时，网页节点在采集前把 `(caller_name, kind, active = true)` 推送给页面状态栏并记入内存使用记录，采集结束后立即更新为 `active = false`（即使采集失败也会清理），页面始终可见当前正在使用或最近使用过该能力的设备名。
