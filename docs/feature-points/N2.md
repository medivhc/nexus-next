# N2 功能点与验收标准：省电策略与稳定回退

对应 RFC v0.1 阶段 **N2**（覆盖用户场景 U10、U12 及第 9 节低功耗设计），解决当前 Android 默认 `multipath=true` 强制保活蜂窝网络的耗电问题，并保障 60 秒内快速回退。

## 验收门禁

1. **默认不强制拉起蜂窝**：Android 未显式指定 `realtime` 或 `--ez multipath true` 时，默认进入 `Balanced` 模式，`keep_cellular_with_wifi = false`，日志不得出现主动请求蜂窝网络的行为。
2. **按需开启实时多路径**：用户主动切换至 `Realtime` 模式（或显式传入 `--es power_mode realtime` / `--ez multipath true`）时，才调用 `ConnectivityManager.requestNetwork(TRANSPORT_CELLULAR)`；切回 `Balanced` / `PowerSave` 或停止 VPN 时必须注销对应的 `NetworkCallback`。
3. **快速回退**：应用内「停止 VPN」按钮或停止 Intent 触发后，10 秒内（远低于 60 秒目标）释放 TUN 与所有网络回调，系统恢复既有网络方案。
4. **功耗数据诚实性**：不在无真实手机 Batterystats / 电量计 A/B 实测前宣称节电百分比；真机 8 小时息屏对照项标为 `BLOCKED（待真机执行）`。

---

## FP-N2-01 电源模式策略映射（纯逻辑确定性）
- **Given** 电源模式为 `Balanced`、`PowerSave`、`Realtime`
- **When** 查询 `PowerPolicy::for_mode(mode)`
- **Then**
  - `Balanced`：`keep_cellular_with_wifi == false`，`allow_multipath_redundancy == false`，`idle_probe_interval_secs == 60`
  - `PowerSave`：`keep_cellular_with_wifi == false`，`allow_multipath_redundancy == false`，`idle_probe_interval_secs == 180`
  - `Realtime`：`keep_cellular_with_wifi == true`，`allow_multipath_redundancy == true`，`idle_probe_interval_secs == 15`
- **And** 默认模式为 `Balanced`；无法识别的模式字符串安全回退到 `Balanced`

## FP-N2-02 Android 默认启动不请求蜂窝网络
- **Given** 安装最新 `nexus.apk` 到 Android 设备/redroid
- **When** 不带 `--ez multipath true` 和 `--es power_mode realtime` 启动 `MainActivity`
- **Then** `NexusVpnService` 以 `balanced` 模式启动，`keepCellular` 保持为 `null`，`logcat` 记录当前电源模式为 `balanced（不主动保持蜂窝）`

## FP-N2-03 实时多路径模式按需启停与回调清理
- **Given** `NexusVpnService` 正在 `balanced` 模式运行
- **When** 用户在 UI 切换至「实时多路径」（或通过 Intent 传入 `--es power_mode realtime`）
- **Then** 服务切换到 `realtime` 模式并请求蜂窝网络（无蜂窝硬件的模拟器记录告警但不崩溃）
- **When** 用户切回「平衡省电」或点击「停止 VPN」
- **Then** 已注册的蜂窝 `NetworkCallback` 被安全注销，无资源泄漏

## FP-N2-04 60 秒内快速回退（规则与 VPN 双层）
- **Given** Android 上 Nexus VPN 正在运行且导入了测试规则
- **When** 用户点击「停止 VPN」（或执行 `am start -n link.bewith.nexus/.MainActivity --es action stop`）
- **Then** VPN 服务在 5 秒内停止，TUN 描述符关闭，系统网络恢复默认路由，原有其他 VPN 应用未被卸载、可直接重新启用
