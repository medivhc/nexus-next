# M10.2 功能点：完整能力 MCP 服务

## 模型

- `nexus mcp` 是面向 AI agent（如 Claude Code、Cursor、Gemini CLI 等）的标准 JSON-RPC 2.0 MCP 服务器（标准输入输出），原本仅暴露 4 个基础工具（`nexus_ls`、`nexus_status`、`nexus_exec`、`nexus_session_ls`）。
- M10.2 将 `nexus mcp` 扩展为覆盖设备与服务发现、远端命令与常驻会话、版本化工作区（Drive）读写与提交、网络路径与路由诊断、本机审计查询的 16 个完整工具，全部走统一的本机控制协议与最小权限授权体系：
  - **设备与服务发现**：`nexus_ls`、`nexus_status`、`nexus_services`。
  - **远端执行与终端会话**：`nexus_exec`（新增可选 `env` 环境变量数组）、`nexus_session_ls`、`nexus_session_kill`。
  - **工作区（Drive）**：
    - `nexus_drive_ls`（列出工作区或目录，支持 `--at` 提交引用）
    - `nexus_drive_read`（按范围读文件；UTF-8 无 NUL 文本以 `encoding: "utf-8"` + `content` 返回，二进制以 `encoding: "base64"` + `content_base64` 返回，带 `schema`、`path`、`size`）
    - `nexus_drive_write`（写入文本 `content` 或二进制 `content_base64`，支持 `exec` 可执行位）
    - `nexus_drive_rm`（删除文件或目录，支持 `recursive`）
    - `nexus_drive_status`（查看未提交改动）
    - `nexus_drive_commit`（提交改动并同步）
    - `nexus_drive_where`（查看数据副本位置、同步状态和本机缓存）
  - **网络诊断与审计**：`nexus_path`、`nexus_route_explain`、`nexus_audit`。
- 所有工具在携带 `--agent` 或 `NEXUS_AGENT` 时自动以该 agent 凭据的身份执行，受相同能力与资源授权约束（例如仅有 `drive.read@<node>/drive/<ws>` 时允许列目录和读文件，拒绝写入和审计查询），且每次操作都在被访问设备上产生审计记录。
- 工具出错（缺少参数、无权限、目标不存在、非法 base64 等）统一返回 `isError: true`，并在 `structuredContent` 中给出结构化错误对象。

## FP-10.2-01 工具目录完整且模式合法（R76）
- Given 网络已建立，启动 `nexus mcp`
- When 客户端发送 `initialize` 与 `tools/list`
- Then 返回全部 16 个工具，每个工具包含非空 `description` 与 `type: "object"` 的 `inputSchema`

## FP-10.2-02 经 MCP 读写与提交工作区文件（R76）
- Given 设备上已创建工作区 `work`
- When 客户端依次调用 `nexus_drive_write`（文本与二进制 base64）、`nexus_drive_ls`、`nexus_drive_read`（全文与 `offset`/`length` 分段读）、`nexus_drive_status`、`nexus_drive_commit`、`nexus_drive_where`、`nexus_drive_rm`
- Then 文本返回 `encoding: "utf-8"` 且内容逐字节一致，二进制返回 `encoding: "base64"` 且解码后逐字节一致，未提交改动、提交记录、副本位置和删除均正确返回结构化结果

## FP-10.2-03 经 MCP 发现服务、诊断路径/路由与查审计（R76）
- Given `home` 发布了服务 `web`，`laptop` 添加了路由规则
- When `laptop` 经 MCP 调用 `nexus_services`、`nexus_path`、`nexus_route_explain`、`nexus_audit`
- Then 均返回 `isError: false` 与各自对应的结构化字段

## FP-10.2-04 经 MCP 调用受 agent 最小权限与审计约束（R76）
- Given 为 agent 签发仅包含 `drive.read@laptop/drive/work` 与 `node.info@home` 的凭据
- When 以 `--agent` 运行 `nexus mcp`，分别调用 `nexus_drive_ls`、`nexus_drive_read`、`nexus_drive_write`、`nexus_audit`
- Then `nexus_drive_ls` 与 `nexus_drive_read` 成功返回；`nexus_drive_write` 与 `nexus_audit` 返回 `isError: true` 且错误码为 `denied`
