# M9.1 功能点：临时分享（文件/目录、网页服务、只读终端）

对应需求：`FEATURES.md` **R73**（并遵循 **R17**、**R32**）。

## 设计要点

1. **向前兼容的协议扩展（协议 19.2：`WIRE_VERSION = 19, WIRE_MINOR = 2`）**：
   - 在 `Request` 末尾新增 `ShareOpen { token }`、`ShareDriveList { token, path }`、`ShareDriveRead { token, path, max }`、`ShareServiceConnect { token }`、`ShareSessionWatch { token, size }`；在 `Response` 末尾新增 `ShareOpened(ShareInfo)`、`ShareDriveEntries(Vec<ShareDriveEntry>)`、`ShareDriveFile { size, bytes, truncated }`。
   - 在 `CtlRequest` / `CtlResponse` 末尾新增 `ShareCreate`、`ShareList`、`ShareRevoke` 及回应，既有消息编码保持不变（19.0、19.1 的 fixture 不动）。
2. **三类只读分享目标与细粒度隔离**：
   - **文件或目录（`ShareTarget::Drive { ws, path }`）**：基于本机工作区树与 CAS，仅允许列出和读取被分享路径之内的内容（分享单文件时不可列出其他文件；分享子目录时不可越界访问上级或其他目录）。
   - **已发布的网页服务（`ShareTarget::Service { name }`）**：仅限已发布的 `--proto http` 服务，访客连接按流转发到该服务。
   - **只读终端观看（`ShareTarget::Terminal { session }`）**：访客附着到已有终端会话，实时接收屏幕快照与输出并可发送 `Ack` / `Ping`，但服务端严格丢弃任何 `Input::Stdin` 与 `Input::Resize`，且访客以观看者身份附着，永远不成为活跃客户端、不改变原会话的终端尺寸（绝对只读，不干扰原会话），并在分享被撤销或到期时立即断开流。
3. **到期时间、次数上限、随时撤销与审计**：
   - 创建分享（`nexus share create`）时指定 `--ttl`（默认 `1h`）和可选 `--max-uses <N>`，生成 128 位随机 token 及 `#share=<token>&node=<node_id>&hint=<hint>` 访客链接（不需通行密钥，用完即走，满足 R32）。
   - 每次 `ShareOpen` 校验未撤销、未到期、且 `uses < max_uses` 并扣减一次可用次数，同时记下这个访客；后续子请求同样校验未撤销、未到期，且只接受打开过这项分享的访客（跳过 `ShareOpen` 直接访问会被拒绝，次数上限不能被绕过）；支持 `nexus share ls` 查看剩余状态与 `nexus share revoke <id>` 随时撤销。
   - 每一次访客打开或访问（包括因过期、次数耗尽、已撤销或路径越界被拒绝的尝试）均写入本机审计日志（`capability` 为 `share.open` / `share.drive` / `share.service` / `share.terminal`，主体标记为 `share:<id>`）。
