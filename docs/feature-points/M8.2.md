# M8.2 功能点：网页里打开已发布的网页服务

## 模型

- 网页节点核心提供两个操作（浏览器和测试里是同一份代码）：
  - **列出服务** `<设备>`：设备上它有 `svc.connect` 授权的服务，每项有名字、协议、说明里的环境变量。
  - **发一个 HTTP 请求** `<设备>/<服务>` + 方法、路径（含 `?` 后面）、请求头、正文：经 Nexus 连到服务，
    用 HTTP/1.1 发出（`Host: localhost`、`Connection: close`，去掉逐跳的头），读完回应：状态码、回应头（去掉逐跳的头）、正文。
    正文按 `Content-Length`、`chunked` 或读到连接结束；中间的 `1xx` 回应跳过；超过 64 MiB 时 `InvalidInput`。
    协议不是 `http` 时 `InvalidInput`；没有授权 `Denied`；服务不存在 `NotFound`；服务的程序没在运行 `Unreachable`。
- 页面：
  - 设备列表里，每台设备后面列出它上面的网页服务（只列 `http` 的），每个是一个在新标签页打开的链接
    `/svc/<令牌>/`。令牌是 128 位随机数，登录的页面在内存里记着它对应哪个设备和服务。
  - 转发程序（Service Worker，`sw.js`，作用于整个站点）接住 `/svc/<令牌>/…` 的请求，以及从服务的标签页发出的其他请求
    （服务的页面用绝对路径 `/static/app.js` 时，按发出它的标签页或 Referer 找到令牌），把令牌和请求交给登录的页面；
    登录的页面按令牌找到设备和服务，用网页节点核心发出，回应交还。不认得的令牌：503。
    登录的页面自己的文件不经过它。
  - 隔离：服务的页面和登录的页面同一个站点，但服务在别的标签页里打开（`noopener`），拿不到登录的页面；
    它只知道自己的令牌，所以只能访问自己。
  - cookie：服务回应的 `Set-Cookie` 记在登录的页面内存里（按令牌，只记名字和值；`Max-Age<=0` 或过期时删除），
    之后发给同一服务的请求带上 `Cookie`，浏览器自己不保存；请求里浏览器自带的 `Cookie` 去掉。
  - 跳转：`Location` 是本服务的绝对路径或 `http://localhost…`/`http://127.0.0.1…` 时改写到 `/svc/<令牌>/…`。
  - 转发程序只在有网页服务可打开时注册。登录的页面关闭时注销，并清掉这个站点下的浏览器存储
    （服务的页面可能用了 localStorage、cookie、IndexedDB、Cache）；页面打开时先做同样的清理再显示登录。

## FP-8.2-01 列出服务、发请求（R71）
- Given home 发布了 `web`（http，回显请求的测试服务）、`echo`（tcp）
- And 通行密钥 phone 登记时授权 `node.info@**`、`svc.connect@**`
- When 浏览器用 phone 登录，列出 home 上的服务
- Then 有 web（http）和 echo（tcp）
- When `GET /hello?x=1`
- Then 200，正文是服务回显的 `GET /hello?x=1`（分块传输也完整拼好），回应头里有服务的 `Set-Cookie`，没有 `Transfer-Encoding`
- When `POST /form`，正文 `a=1`，带 `Cookie: visited=yes`
- Then 正文里有 `POST /form`、`cookie: visited=yes`、`body: a=1`
- When `GET /go`：302，`Location: /landed`（核心不跟随跳转，交给页面）

## FP-8.2-02 打不开（R71）
- 对 echo（tcp）发请求：`InvalidInput`；不存在的服务：`NotFound`
- 服务的程序停了：`Unreachable`
- 只有默认授权的通行密钥：列出的服务是空的；发请求：`Denied`；home 的审计里有记录

## FP-8.2-03 页面里打开（R71，真实浏览器）
- home 上用一个普通的 HTTP 服务器发布一个小网站：`index.html` 里有相对路径的图片、绝对路径的脚本（脚本改写页面上的一段文字）、
  一个绝对路径的链接 `/about.html`
- 登录后设备列表里 home 后面有 web；点开：新标签页 `/svc/<令牌>/` 里服务的页面显示出来，图片加载了，脚本运行了
- 点绝对路径的链接：打开的是服务的 `about.html`，地址还在 `/svc/<令牌>/` 下面
- 不认得的令牌 `/svc/000…/`：503
- 页面被关掉后浏览器里没有转发程序的注册，也没有其他存储（R32）
