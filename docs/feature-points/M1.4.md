# M1.4 功能点：常驻终端

`nexus ssh <节点>` 进入另一台设备上的一个常驻终端会话。会话有名字（默认 `main`），不存在时自动创建。
会话属于那台设备，不属于连上去的客户端：客户端断开、网络中断，会话里的程序照常运行。

断开：按 `Ctrl-]`，或者标准输入结束。会话里的 shell 退出时会话结束，客户端以 shell 的退出码退出。

## FP-1.4-01 不用密码进入终端（R04）
- Given laptop 和 home 在同一个网络里，双方都没有配置过任何密码或密钥
- When 在 laptop 上 `nexus ssh home`，输入 `echo hello`
- Then 屏幕上出现 `hello`
- When 目标是名册里没有的节点
- Then 退出码 103

## FP-1.4-02 断开后会话继续运行（R05）
- Given 连着 home 的会话，执行 `sleep 2; echo during`
- When 立刻断开，3 秒后重新连上
- Then 屏幕上有 `during`：断开期间命令照常运行并完成

## FP-1.4-03 全屏程序的画面被恢复（R06）
- Given 会话里运行着一个占用整个屏幕的程序（进入备用屏幕并画出 `FULLSCREEN`）
- When 断开后重新连上
- Then 看到的仍是全屏程序的画面
- And 全屏程序退出后，回到它下面原来的 shell 内容

## FP-1.4-04 多个客户端共享一个会话（R07）
- Given laptop 和 phone 同时连着 home 的同一个会话
- When laptop 输入一条命令
- Then 两边都看到这条命令和它的输出；phone 输入的命令同样两边可见
- And 会话的终端尺寸跟随最近一次输入的客户端：phone（100x30）输入 `stty size` 看到 `30 100`，laptop（80x24）输入时看到 `24 80`

## FP-1.4-05 慢客户端不拖慢别人（R08）
- Given laptop 和 phone 连着同一个会话，laptop 停止读取输出（例如终端被挂起）
- When phone 执行一条输出几 MB 的命令，最后输出 `DONE`
- Then phone 很快看到 `DONE`
- When laptop 恢复读取
- Then laptop 也看到 `DONE`，屏幕和 phone 一致；中间错过的输出被跳过，而不是慢慢补完

## FP-1.4-06 网络中断后自动恢复（R23）
- Given laptop 连着 home 的会话，执行 `sleep 2; echo after-outage`
- When laptop 和 home 之间的网络中断 4 秒后恢复
- Then 不需要任何操作，laptop 的屏幕上出现 `after-outage`，会话仍可继续输入

## FP-1.4-07 会话管理（R05）
- When `nexus session ls home`
- Then 列出 home 上的会话：名字、连着的客户端数、创建时间；`--json` 时是结构化的
- When `nexus session kill home main`
- Then 会话结束，连着它的客户端退出；之后 `session ls` 里没有它
- When 会话里的 shell 执行 `exit 7`
- Then 客户端以退出码 7 退出，会话随之结束
- When kill 一个不存在的会话
- Then 退出码 109（not_found）

## FP-1.4-08 名字不同的会话互不相干（R05）
- When `nexus ssh home --session work`
- Then 这是一个独立的会话，`main` 里的内容不会出现在这里
