# N6 功能点与验收标准：显式 HTTP 改写、Map Local 与策略模拟

## FP-N6-01 Map Local 本地模拟响应（U08）
- **Given** 配置 `HttpRule` 匹配 `api.dev.test` 路径前缀 `/v1/mock`，动作 `MapLocal { status: 200, body: "{\"ok\":true}" }`
- **When** 客户端经显式 HTTP 代理请求 `GET http://api.dev.test/v1/mock`
- **Then** 代理直接返回 200 与 `{"ok":true}`，不向真实上游建连，且记录脱敏 `FlowEvent`
- **When** 客户端请求 `GET http://prod.example.com/v1/mock`
- **Then** 不命中规则，原样透传，不影响生产请求

## FP-N6-02 测试服务重定向与请求头改写（U08）
- **Given** 配置 `RedirectTarget` 将 `api.dev.test` `/v1/` 重定向至本地测试服务端口，或配置 `ModifyRequestHeaders` 注入 `X-Env: staging`
- **When** 客户端经显式 HTTP 代理请求 `http://api.dev.test/v1/hello`
- **Then** 请求被转发到测试服务并携带改写后的请求头，收到测试服务响应

## FP-N6-03 开发环境故障模拟注入（U08）
- **Given** 配置 `FaultInject { status: 503 }` 匹配 `flaky.dev.test`
- **When** 请求 `http://flaky.dev.test/`
- **Then** 代理直接返回 `503 Service Unavailable`，便于客户端容错测试

## FP-N6-04 Agent 只读策略模拟验证（RFC 10.2）
- **Given** Agent 调用 MCP `nexus_policy_simulate`，传入候选 Clash 规则文本与待测目标列表
- **When** 执行模拟
- **Then** 返回导入审计报告、静态冲突检查及每个目标的预期去向，**且不修改节点当前生效的路由表**
